# Müzik Mağazası Otomasyonu

C# Windows Forms ile geliştirilmiş müzik enstrüman satış mağazası yönetim sistemi.

## Özellikler
- Enstrüman (ürün) ekleme, düzenleme, silme
- Stok takibi
- Satış işlemleri
- Müşteri kayıtları

## Kullanılan Teknolojiler
- C# / Windows Forms (.NET Framework)
- SQL Server LocalDB
- Visual Studio

## Kurulum
1. Repoyu indir (Code → Download ZIP).
2. SQL Server LocalDB'de MuzikShpDb adında bir veritabanı oluştur.
3. veritabani.sql dosyasını bu veritabanında çalıştır.
4. .slnx dosyasını Visual Studio ile aç ve çalıştır.
